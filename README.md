# Address Book Management System
## 📌 About the Project

This is a simple Address Book application developed using C programming.
It allows users to manage contact information such as name, phone number, and email address.

## ✨ Features

* Add a new contact
* Search for a contact
* Edit a contact
* Delete a contact
* Display all contacts
* Save contacts to a file
* Load contacts from a file

## 🛠️ Concepts Used

* C Programming
* Structures
* Functions
* Pointers
* Strings
* File Handling
* Arrays
* Menu-driven programming

## ▶️ How to Run

Compile the program using:
gcc *.c -o addressbook

Then run:
./addressbook
